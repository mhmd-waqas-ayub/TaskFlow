## 📌 Overview

TaskFlow is a full-stack real-time project management platform built using the MERN stack. It enables users to create projects, manage tasks through a Kanban workflow, collaborate in real time, and track productivity through analytics dashboards.

## 🔄 Application Workflow

1. User registers or logs in.
2. JWT token is generated and verified.
3. Protected routes authorize access.
4. Users create projects and tasks.
5. Tasks move through the Kanban workflow.
6. Socket.IO synchronizes updates in real time.
7. Analytics dashboard displays productivity metrics.
